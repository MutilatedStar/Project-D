# Signal Lab - 16x16 Modular Sci-Fi Interior Pack

Build modular sci-fi labs, control rooms, research stations and futuristic interiors.

## Included

- 36 base sprites
- 108 sprite variants across Arctic, Solar and Violet colorways
- 16x16, 32x32 and 48x48 PNG exports
- Per-colorway spritesheets at all three sizes
- Floors, walls, doors, equipment, props, bots, character and UI icons
- CSV metadata and JSON manifest
- Commercial-use license

## Suggested Engine Setup

- Import the 16x16 folder for native pixel-art projects.
- Use the 32x32 or 48x48 folders for higher-resolution projects or UI thumbnails.
- Keep image filtering set to nearest-neighbor / point filtering.
- Use the per-colorway spritesheets when building tilemaps.
