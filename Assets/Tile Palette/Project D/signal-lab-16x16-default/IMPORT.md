# IMPORT - Signal Lab - 16x16 Modular Sci-Fi Interior Pack

Native grid: **16 x 16 px (exported at 16, 32 and 48 px), 3 palettes**

36 base sprites x 3 palettes = 108 sprites, at three sizes.

    sprites/16x16/<palette>/<name>.png     native
    sprites/32x32/<palette>/<name>.png
    sprites/48x48/<palette>/<name>.png
    spritesheets/                           atlases, see below
    palettes: arctic, solar, violet
    categories: Floor Wall Door Equipment Prop Bot Character UI

## Godot 4.x

1. Copy `sprites/16x16/arctic/` into `res://signal_lab/`.
2. Project Settings > Rendering > Textures > **Default Texture Filter = Nearest**.
3. `TileSet` > **Atlas source** > point at the folder > **Texture Region Size = 16 x 16**,
   Margin 0, Separation 0. Paint with a `TileMapLayer`.
4. Doors and terminals are normal tiles here; if you want them interactive, give the
   cell a `custom_data_layer` and read it from a script.
5. Palette swap: the three palettes are separate folders of the same 36 names, so
   switching is a path change, not a shader.

## Unity 2022.3 LTS

1. Copy `sprites/16x16/arctic/` into `Assets/SignalLab/`.
2. Select all: **Texture Type = Sprite (2D and UI)**, **Sprite Mode = Single**,
   **Pixels Per Unit = 16**, **Filter Mode = Point**, **Compression = None**,
   **Generate Mip Maps = off**. Apply.
3. **Window > 2D > Tile Palette > New Palette**, drag the 36 sprites in, paint.
4. For the 32 / 48 px folders use PPU 32 / 48 and keep them out of the same palette
   as the 16 px set.

## About the `spritesheets/` folder

Nine atlases: one per palette per size.

    arctic-16x16.png   96 x 96    6 x 6 grid of the 36 sprites at native 16 px
    arctic-32x32.png   192 x 192  the same 36 at 32 px
    arctic-48x48.png   288 x 288  the same 36 at 48 px
    and the same three for solar and violet

Sprites run left to right, top to bottom, in the same alphabetical order as
`sprites/<size>/<palette>/`, so cell (row, column) is the same sprite in every
atlas. Slice at the size in the filename: 16, 32 or 48.

Godot: `TileSet` > **Atlas source** > pick an atlas > **Texture Region Size = 16 x 16**
(or 32/48 to match). Unity: Sprite Mode **Multiple**, then Slice > Grid By Cell Size.

## How these files were made

Everything here is generated by original Python code (Python 3, numpy, Pillow)
written for this shop. There is no stock art, no tracing, no photo texture, no
scanned material and no third-party asset in any of it.

The generator code was written with AI assistance, so the store's listings
declare generative AI assistance for graphics. The output itself is ordinary
deterministic pixel/vector art: fixed grid, fixed palette per material, no
image-model output.

Practical consequence for you: nothing here is hand-painted, so it is stylistically
consistent and very cheap to recolour, but it is also more regular than a hand-drawn
set. Neutrals and keywords ("fantasy icons", "sci-fi HUD") are what it does best.

## Known limitations

The pack is dark-palette sci-fi: most props are a rounded dark shape with one
emissive accent bar, so `barrel`, `crate`, `toolbox` and `workbench` share a
silhouette and differ mainly in the accent. Floor tiles are flat colour with almost
no texture. Good for a sleek HUD-heavy lab, weak for a grungy one.
